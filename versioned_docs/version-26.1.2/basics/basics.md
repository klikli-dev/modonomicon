# Basics

This section covers the core building blocks of a Modonomicon book.

- **[Book Structure](./structure)** — Categories, entries, pages, and commands
- **[Page Types](./page-types)** — Text, spotlight, image, entity, recipe, multiblock, scholarship, and empty pages
- **[Formatting](./formatting)** — Markdown syntax, links, colors, and dynamic text macros
- **[Crafting](./crafting)** — Recipe page configuration details
- **[Unlock Conditions](./unlock-conditions)** — Locking content behind conditions
- **[Research](./research)** — Facts, values, nodes, hooks, and triggers
- **[Scholarship](./scholarship)** — The research blocks and rows that players see and interact with

Conditions, research and scholarship are three separate layers: conditions unlock content, research holds the data and the server logic, and scholarship draws research on the pages. See the [Glossary](./research/glossary.md#condition-research-and-scholarship).
